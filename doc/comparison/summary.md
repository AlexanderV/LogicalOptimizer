# Cross-library comparison — OUR-side artifacts (roadmap P0.2)

Generated by `LogicalOptimizer.Benchmarks -- comparison-suite`. Every OUR number
below comes from the committed artifact [`our-results.json`](our-results.json);
the run environment is in [`manifest.json`](manifest.json). Competitor columns are
left `pending (run …)` — they are **never** filled in here from memory; run the
named command where the external tool is installed and merge (see
[`doc/COMPARISON_METHODOLOGY.md`](../COMPARISON_METHODOLOGY.md) and
[`tools/comparison/`](../../tools/comparison/)).

**Reproduce (OUR side, single command):**

```powershell
dotnet run -c Release --project LogicalOptimizer.Benchmarks -- comparison-suite
```

Timings are machine-dependent and indicative (median of 7 after 1 warm-up); 
they are **never** asserted. Sizes, counts, statuses, verdicts and model counts 
are deterministic given the corpus.
